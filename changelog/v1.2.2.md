# v1.2.2 — 2026-02-21

## Fixed

### `vite.config.ts` — middleware sentinel comment indentation
The `// Add more page rewrites here as needed for new pages` comment inside
`devServerMiddleware()` had its indentation stripped, which would have caused
`scripts/create-page.js` to fail silently when injecting new page routes.
Indentation restored to match the expected pattern.

### `vite.config.ts` — stray blank lines in `rollupOptions.input`
Removed nine trailing blank lines inside the `rollupOptions.input` object that
were left behind from a previous cleanup pass.

## Changed

### `AGENTS.md` — explicit "never commit unless asked" instruction
Replaced the two pre-commit instructions with three clearer rules:
1. **Never** commit, push, or touch the changelog proactively — wait for an
   explicit user request.
2. When a commit is requested: audit and update affected `docs/` first.
3. When a commit is requested: generate/update the changelog first.

Also added the PR message template and generation instruction (committed
separately as `docs(agents): add PR message template`).

## Added

### `@radix-ui/react-slot` dependency
Added `@radix-ui/react-slot@^1.2.4` to `dependencies` (pulled in as a peer
requirement for shadcn/ui button primitives).
