## Overview

v1.2.0 makes the template production-launch ready. It adds a full GitHub Actions CI/CD pipeline that type-checks, lints, tests, builds, and deploys to GitHub Pages on every push to `main`. It also adds complete SEO meta tags, Brotli/gzip asset compression, and wires in the Tailwind typography plugin.

---

## Added

### GitHub Actions CI/CD Pipeline

New file: `.github/workflows/ci.yml`

Four-job pipeline triggered on every push to `main` and every PR against `main`:

```
compile (type-check) → test (lint + unit) → build → deploy (main only)
```

- **compile** — runs `npm run type-check` (TypeScript strict check)
- **test** — runs `npm run lint` + `npm run test` (vitest unit suite)
- **build** — runs `npm run build` with `BASE_URL=/sasstify-frontend-template/` for GitHub Pages sub-path; uploads `dist/` as artifact
- **deploy** — downloads artifact, configures Pages, uploads and deploys; only runs on `push` to `main` (not PRs or forks)

Key configuration:
- Node 20 LTS, `ubuntu-latest`
- `npm ci` with npm cache for fast installs
- `concurrency` cancel-in-progress to save CI minutes
- `permissions: pages: write, id-token: write` scoped to deploy job

### SEO Meta Tags

Added to `src/pages/index/index.html`:

- **Canonical link** — `<link rel="canonical">` pointing to GitHub Pages URL
- **Open Graph** — `og:type`, `og:url`, `og:title`, `og:description`, `og:image` (1200×630)
- **Twitter Card** — `twitter:card`, `twitter:title`, `twitter:description`, `twitter:image`
- **Structured Data** — `ld+json` schema (`SoftwareSourceCode`) with name, description, repo URL, languages, license, and free offer

### Brotli + Gzip Compression

`vite-plugin-compression` is now wired into `vite.config.ts` (it was previously installed but unused):

```typescript
import viteCompression from 'vite-plugin-compression';

// production plugins:
viteCompression({ algorithm: 'brotliCompress', ext: '.br' }),
viteCompression({ algorithm: 'gzip', ext: '.gz' }),
```

Actual compression ratios from the current build:

| Asset | Raw | Gzip | Brotli |
|---|---|---|---|
| CSS | 39 KB | 7 KB | 5.8 KB |
| React vendor | 848 KB | 351 KB | 290 KB |
| UI vendor | 109 KB | 45 KB | 38 KB |
| Page code (all chunks) | ~71 KB | ~34 KB | ~30 KB |

### Tailwind Typography Plugin

`@tailwindcss/typography` (already in `devDependencies`) is now registered in `tailwind.config.ts`:

```typescript
import typography from "@tailwindcss/typography";
plugins: [typography],
```

Enables the `prose` utility class for rich-text content areas.

### Sitemap

Added `public/sitemap.xml` listing the two live pages with `lastmod`, `changefreq`, and `priority`.

## Changed

### Vite Config Base Path

Added `base: process.env.BASE_URL ?? '/'` to `vite.config.ts`. Defaults to `/` for local dev and normal deployments; set to `/sasstify-frontend-template/` in the CI workflow for GitHub Pages sub-path.

### Hero Stats Updated

Verified against a real production build:
- **Initial Bundle**: `79 KB` → `~70 KB` (uncompressed page-specific JS, vendor chunks cached separately)
- Matching copy in `IndexFeaturesSection.tsx` updated to match

### Package Engines Field

Added to `package.json`:
```json
"engines": { "node": ">=20.0.0", "npm": ">=10.0.0" }
```
