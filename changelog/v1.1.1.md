## Changed

### Documentation Updates

All references to the old component directory layout and removed pages were updated across 30+ documentation files:

**Component path corrections (all docs):**
- Import paths updated from `components/layout/layout/Layout` → `components/blocks/layout/Layout`
- Import paths updated from `components/header/Header` → `components/ui/header/Header`
- Same fix applied for `footer`, `section`, and `viewport-lazy-load` across all docs

**Page inventory corrections:**
- All `src/pages/dashboard/` references replaced with `src/pages/page-not-found/`
- All `dist/dashboard/` build output examples replaced with `dist/page-not-found/`
- Vite config examples updated from `dashboard:` input key to `'page-not-found':` key

**Section component name corrections:**
- `HeroSection` → `IndexHeroSection`, `FeaturesSection` → `IndexFeaturesSection`, `AboutSection` → `IndexAboutSection` in lazy-loading and reusable-implementations docs
- Old `src/components/sections/` path → correct `src/pages/index/` path

**Files updated:**

### AGENTS.md Updates

Added workspace memory file at project root with:

- **Learned User Preferences** — pre-commit checklist (docs sync, changelog, commit message format), scaffold script usage, content centralisation, performance targets, testing approach
- **Learned Workspace Facts** — directory layout, sentinel comment in `vite.config.ts`, pending tasks, template purpose

New preference rules added during this session:
- Keep all docs in sync with code changes before every commit
- Generate or update `changelog/vX.Y.Z.md` before every commit
- Commit messages must follow Conventional Commits format as defined in `docs/contributing/02-commit-conventions.md`
