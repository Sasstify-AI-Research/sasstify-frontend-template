# Release v1.1.2 - Fix Broken Dashboard Links on Index Page

**Release Date:** February 21, 2026
**Type:** Patch Release — Bug Fix

---

## Overview

Removes two broken links to the deleted `/dashboard/` page on the index page and replaces them with meaningful content pointing to the GitHub repository.

---

## Fixed

- **`IndexHeroSection.tsx`** — "View Dashboard" CTA button in the hero section now links to the GitHub repository ("View on GitHub") instead of the removed `/dashboard/` route.
- **`Index.tsx`** — "Want to See More Examples?" section in the demo area updated:
  - Heading changed from "Want to See More Examples?" → "Want to Use This Template?"
  - Body copy updated from "Visit the Dashboard page to see lazy-loaded modal examples." → "Explore the source code, documentation, and scaffold scripts on GitHub."
  - Button label changed from "Go to Dashboard →" → "View on GitHub →"
  - `href` updated from `/dashboard/` → `https://github.com/software-engineer-404/sasstify-frontend-template` (opens in new tab)
